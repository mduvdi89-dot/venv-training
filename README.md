# 🐍 Python Virtual Environment (venv) Training
این پروژه یک راهنمای عملی برای یادگیری نحوه مدیریت صحیح محیط‌های مجازی در پایتون و آپلود استاندارد پروژه‌ها در گیت‌هاب است.

## 🚀 چرا از venv استفاده می‌کنیم؟
برای اینکه کتابخانه‌های هر پروژه با بقیه سیستم قاطی نشه و تداخلی ایجاد نکنه. با این کار پروژه‌ی شما روی هر سیستمی به راحتی اجرا میشه.

## 🛠 نحوه راه‌اندازی (Setup)

### ۱. شبیه‌سازی پروژه (Clone)
ابتدا پروژه را در سیستم خود کپی کنید:
```bash
git clone https://github.com/mduvdi89-dot/venv-training.git
cd venv-training
```

### ۲. ساخت محیط مجازی (Create venv)
برای ساخت محیط مجازی دستور زیر را در ترمینال بزنید:
```bash
python3 -m venv .venv
```

### ۳. فعال‌سازی (Activation)
*   **در مک و لینوکس:**
    ```bash
    source .venv/bin/activate
    ```
*   **در ویندوز:**
    ```bash
    .venv\Scripts\activate
    ```

### ۴. نصب پیش‌نیازها (Install Dependencies)
حالا کتابخانه‌های لازم را نصب کنید:
```bash
pip install -r requirements.txt
```

---

## 📂 ساختار استاندارد فایل‌ها
در این پروژه موارد زیر رعایت شده است:
- **`.venv/`**: پوشه محیط مجازی (که نباید در گیت‌هاب آپلود شود).
- **`.gitignore`**: لیستی از فایل‌هایی که گیت نباید آن‌ها را آپلود کند (مثل خودِ `.venv`).
- **`requirements.txt`**: لیست تمام کتابخانه‌های استفاده شده در پروژه.

## ⚠️ نکات مهم برای گیت‌هاب
هرگز پوشه محیط مجازی را آپلود نکنید! همیشه از دستور زیر برای ثبت کتابخانه‌ها استفاده کنید:
```bash
pip freeze > requirements.txt
```
